# Spell Catalog provenance and verification

The catalog contains the 339 spell descriptions in the official [SRD 5.2.1 PDF](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf), pages 107–175. PDF SHA-256: `8974902d109d6e63672d7c490bde9ccf052410503d9cfa768237154fbc5e3d87`. Retrieved 2026-10-05. It contains only that document's licensed descriptions, not Basic Rules or third-party records. Page 1 grants CC BY 4.0 and requires the full two-sentence attribution presented in About / Legal, including the SRD and license links. The UI identifies formatting changes; Rules Tooltip summaries are application-owned.

`src/data/srd/spell-source-5.2.1.json` preserves the extracted source pages. To reproduce it, install Python pdfplumber and run `python scripts/extract-srd-spells.py /path/to/SRD_CC_v5.2.1.pdf` from the repository root. The extractor verifies the PDF digest, reads actual glyph baseline matrices (font bounding boxes misplace small caps), and orders the left column before the right. This preserves continuation text and floating stat blocks. `node scripts/import-srd-spells.mjs` deterministically generates the bundled JSON offline. Import repairs line-wrapped words while preserving numeric/compound hyphens, normalizes title case, separates components and materials, and associates four creature stat blocks with their owning spells. Descriptions retain source line/row breaks; Teleport and Reincarnate tables are additionally structured into semantic rows and columns. Source pages remain unchanged for audit. No runtime network requests supply catalog data.

Coverage by spell level 0–9: **27, 57, 57, 42, 34, 38, 31, 20, 17, 16**. Tests verify uniqueness, coverage, classes, schools, required fields, per-record version/license/page, flags and materials. Independent primary-source anchors cover True Strike (p171), Cure Wounds (p121), Counterspell (p120), Find Familiar (p130), Fireball (p131), Conjure Animals (p117), and Wish (p175), plus misplaced floating stat-block regression checks. The anchors distinguish this revision from older SRD rules. The initial naive PDF extraction was discarded because floating stat blocks disrupted its reading order.

The `spell-catalog` module hides loading, validation, sorting and composable query rules behind `searchSpells` and `findSpell`. The Magic view owns filters and selection. It does not extend PartyData or persist catalog state; Ticket 12 can reference stable catalog IDs without copying spell descriptions. Removing this module would spread catalog invariants and query behavior into callers.
