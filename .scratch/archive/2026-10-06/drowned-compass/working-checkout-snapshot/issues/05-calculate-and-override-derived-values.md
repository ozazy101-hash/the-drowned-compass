# 05 — Calculate and override Derived Values

**What to build:** The Character Page derives the small set of dependable 2024 values from player-entered information while allowing every result to be explicitly overridden and reset.

**Blocked by:** 04 — Edit and synchronize the Character Overview.

**Status:** ready-for-agent

- [ ] Ability modifiers and proficiency bonus derive from Ability Scores and total level.
- [ ] Saves and skills support none, proficient, and expertise states and display the correct modifiers.
- [ ] Passive Perception, initiative, spell attack modifier, and spell save DC derive from their agreed inputs.
- [ ] Every Derived Value can be overridden, and an override is visually distinguishable from a calculated result.
- [ ] Resetting an override immediately returns the field to its calculated result.
- [ ] Table-driven tests cover normal values, negative modifiers, proficiency thresholds, expertise, and overrides.
