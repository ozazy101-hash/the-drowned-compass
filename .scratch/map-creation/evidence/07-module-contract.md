# Ticket07 module contract

GridMapWorkshop owns creation drafts, private inspection/comparison and recoverable feedback. Its interface takes PartyContent, navigation callbacks and optional explicit presentation callback. Workspace observation is authoritative; no provider, SQL, job ledger or polling timer lives in the UI. MapScene owns reusable SVG scene rendering and keeps artwork visible under terrain overlays. Grid Map domain owns closed outlines and proportional inspection placement. Generation output uses openMapGenerationInput and the accepted server output command; browser output grants no registration authority. Existing GridMapEditor remains the detailed drawing module. No inspection/upload/generation selects presentation. Until10 supplies wiring Use this map is disabled. Images remain private object URLs with asynchronous scope guards and revocation. Failed work retains inputs and saved versions. Server owns all generation timing, proofs, request identity and attachment.
