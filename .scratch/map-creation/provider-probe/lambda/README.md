# Bounded stateless artwork-worker feasibility probe

Module placement/interface recorded before coding: `lambda/worker.mjs` owns one `verifyArtwork(intent)` command with verify/reverify modes. It validates small descriptors, downloads/decodes bounded images, losslessly composes the rectangle, stages one immutable provisional output, and independently checks stored decoded pixels against exact retained source/raw candidate. Reverify reconstructs the same operation and accepts only exact provenance/pixels and canonical encoded identity. Internal fetch/clock vary across real localHTTP and deterministic test transports. Deleting this module would scatter descriptor/deadline/composition/recovery rules across callers. No provider call, job ledger, retry engine, billing, cancellation or accepted attachment exists here;06 owns those.

## Limits and trust

Probe accepts exactly1024×1024, not arbitrary dimensions up to1024. PNG8-bit noninterlaced RGB/RGBA only; APNG acTL/fcTL/fdAT is rejected before baseline decoder allocation. PNG header dimensions must agree with bounded descriptors; streams enforce20MiB even withoutContentLength. Intent16KiB/deadline≤60s; handler sets55s to leave watchdog headroom. Digest, MIME, size, expiry, fixed storage origin/path, no credentials/query/fragment, manual no-redirect fetch and conditional If-None-Match:* provisional writes are enforced. Receipt binds operation/sourceIdentity/sourceDigest/rawCandidateDigest/region; digest-only self-consistency fails independent pixel reconstruction. Exact canonical codec bytes are required as well as pixels. Receipt is server-verification-required evidence, not authority to inherit registration or select display.

These are private synthetic transport fixtures. Source/candidate paths are fixed, provisional path derives from operation identity; fixture invocation/storage authorization is a local constant with no account authority. URLs deliberately reject queries and therefore do **not** establish support for real Supabase signedURL query contracts. The caller-controlled descriptor digest/identity must be populated/authorized by06's trusted server application in production. No AWS IAM, production request authentication or durable storage proof is claimed.

Lost PUT response returns uncertain, never automatic overwrite/repeat provider request. Same-operation reverify reads a provisional object and exact source/raw candidate; malformed/partial images, foreign provenance or inconsistent pixels reject. Late receipts cannot become accepted. Existing-object writes return uncertain for reconciliation; the worker keeps no operation ledger and retains no state beyond the injected transport. The RIE fixture stores synthetic objects in a warm-process Map only; hosted immutable object storage/durable reconstruction remains unproved.
